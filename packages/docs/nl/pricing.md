## Self-Hosted — Gratis (Open-Source)

SlimFact is gebouwd op open-source principes. Als je het liever op je eigen infrastructuur draait, is de volledige applicatie gratis beschikbaar — geen functiebeperkingen, geen proefperiode.

|                              |                                                      |
| ---------------------------- | ---------------------------------------------------- |
| **Prijs**                    | **€0** — gratis                                      |
| **Licentie**                 | ELv2 — gebruik, wijzig en host vrij                  |
| **Infrastructuur**           | Je zorgt zelf voor een server en PostgreSQL-database |
| **Alle functies inbegrepen** | Zelfde functies als Cloud                            |
| **Updates**                  | Pull de nieuwste Docker-images handmatig             |
| **Meerdere bedrijven**       | Onbeperkt                                            |
| **Klanten**                  | Onbeperkt                                            |
| **Facturen**                 | Onbeperkt                                            |
| **Ondersteuning**            | Community-ondersteuning via GitHub                   |

Zie de [README op GitHub](https://github.com/simsustech/slimfact) voor installatie-instructies.

## FAQ

**Kan ik later overstappen van Self-Hosted naar Cloud?**  
Ja. Exporteer je gegevens en we helpen je met de migratie.

**Is er een gratis proefperiode voor Cloud?**  
Ja. Neem contact op en we stellen een proefperiode in zodat je SlimFact kunt uitproberen.

**Zijn er langlopende contracten?**  
Nee. Beide abonnementen zijn maandelijks opzegbaar zonder minimale looptijd.

**Kan ik meerdere bedrijven runnen op één account?**  
Ja. Zowel Cloud als Self-Hosted ondersteunen onbeperkt veel bedrijven onder één account.

**Welke betaalmethoden worden ondersteund voor mijn klanten?**  
iDEAL (via Mollie of Stripe), creditcards (Visa, Mastercard), contant en bankoverschrijving.

**Bieden jullie volume-kortingen?**  
Neem contact op — we kunnen maatwerkprijzen bespreken voor scenario's met hoge volumes.

**Kan ik self-host achter mijn eigen OIDC-provider?**  
Absoluut. Self-Hosted ondersteunt elke OpenID Connect-provider voor authenticatie.
