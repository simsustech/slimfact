## Self-Hosted — Free (Open-Source)

SlimFact is built on open-source principles. If you prefer to run it on your own infrastructure, the full application is available for free — no feature limitations, no trial period.

| | |
|---|---|
| **Price** | **€0** — free |
| **License** | ELv2 — use, modify, and self-host freely |
| **Infrastructure** | You provide your own server and PostgreSQL database |
| **All features included** | Same feature set as Cloud |
| **Updates** | Pull the latest Docker images manually |
| **Multi-company** | Unlimited companies |
| **Clients** | Unlimited clients |
| **Invoices** | Unlimited invoices |
| **Support** | Community support via GitHub |

See the [README on GitHub](https://github.com/simsustech/slimfact) for setup instructions.

## FAQ

**Can I switch from Self-Hosted to Cloud later?**  
Yes. Export your data and we'll help you migrate.

**Is there a free trial for Cloud?**  
Yes. Get in touch and we'll set up a trial period so you can evaluate SlimFact before committing.

**Are there any long-term contracts?**  
No. Both plans are month-to-month with no minimum commitment.

**Can I run multiple companies on one account?**  
Yes. Both Cloud and Self-Hosted support unlimited companies under a single account.

**What payment methods are supported for my customers?**  
iDEAL (via Mollie or Stripe), credit cards (Visa, Mastercard), cash, and bank transfers.

**Do you offer volume discounts?**  
Get in touch — we can discuss custom pricing for high-volume scenarios.

**Can I self-host behind my own OIDC provider?**  
Absolutely. Self-Hosted supports any OpenID Connect provider for authentication.
